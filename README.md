Team #3: Avery Hong, Ruben Reyna, Valeriia Krokhotina, Kensey Celis, Shrinik Madisetty

Tech Stack
- Frontend: React (Vite)
- Backend: Node.js
- Database: MySQL (Azure)

Setup

```bash
cd frontend && npm install
cd ../backend && npm install
```

Run
```bash
cd backend && npm start
cd frontend && npm run dev
```
